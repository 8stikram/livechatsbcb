## 8.4 Cohérence thème × beat

- Le thème est dans la colonne « thèmes les plus cohérents » du beat : **95**.
- Le thème est cohérent avec un autre beat du **même genre** : **75**.
- Sinon : **55**.
- Combinaisons « contre-emploi » (liste fixe : Famille × Rage, Spiritualité × Crank, Santé mentale × Amapiano, Clash × Lovetrap, Soleil × Drill UK, Rue × Pop synthé…) : **30**… mais 10 % de chance de « contre-pied génial » : cohérence comptée à 100 et chance de viral ×2.

## 8.7 Cartes d'embrouille en studio (40)

Format : titre → réactions (P = payer, R = recadrer, C = changer d'approche, I = ignorer). Les effets suivent les archétypes de 03, § 3.6, sauf précision.

**Après le thème (8)**
1. L'artiste veut changer de thème → accepter / R / P un co-auteur.
2. Page à moitié écrite, il bloque → P une séance (+600 €) / R / I (T −10).
3. Le co-auteur réclame un crédit plus gros → P +20 % / R (jet, sinon il part : T redescend d'un niveau) / C.
4. Le thème ressemble trop à un tube récent → C (thème randomisé) / I (15 % de bad buzz « copie »).
5. L'artiste trouve le thème « pas lui » → R / accepter le sien / I (moral −6).
6. Texte trop long → couper (qualité −1, fluide ensuite) / P un arrangeur (+400 €).
7. Fuite du texte sur les réseaux → C / I (découverte −10 %) / en jouer (hype +3, 20 % de bad buzz).
8. La plume star arrive en retard → attendre (+1 tick) / P (+10 %) / C (niveau −1).

**Après le beat (8)**
9. Sample refusé → P les droits / refaire (−3) / I (25 % de procès).
10. Le beat est déjà vendu à quelqu'un d'autre (lease) → P l'exclusif (prix −30 %) / C / I (cohérence −10).
11. L'artiste n'aime pas la prod → R / C (beat randomisé du même genre) / P une retouche (+300 €).
12. Fichiers perdus → P une récupération (+200 €) / C / attendre (+1 tick).
13. Le beat est trop proche d'un son rival → C / I (clash possible à la sortie).
14. Le beatmaker veut être crédité en featuring → accepter (0 €, royalties −2 points pour le label sur ce son) / P (+500 €) / R.
15. Tempo trop rapide pour l'artiste → ralentir (−2) / coaching express (+400 €) / I (jet sur la voix).
16. Une tendance vient de tomber (ce beat baisse) → continuer / C (beat randomisé parmi ceux en hausse).

**Après le producteur (8)**
17. Le producteur ne répond plus → P +30 % / R / attendre.
18. Il veut refaire tout le beat → accepter (50 % : +4 ; 50 % : −3, +1 tick) / R.
19. Conflit d'ego avec l'artiste → R l'artiste / R le producteur / séparer (C) / P un médiateur (+500 €).
20. Il demande une rallonge → P +20 % / R / C.
21. Il a promis le même créneau à un autre label → P la priorité (+25 %) / attendre (+1 tick) / C.
22. Il arrive avec une meilleure idée → suivre (jet sur son niveau : +3 ou −2) / garder le plan.
23. Il impose son ingénieur du son → accepter (+800 €, +1) / refuser (relation −1).
24. Il veut des points sur les royalties → accepter (2 points sur ce son) / P un forfait (+50 % de son prix) / R.

**Après le studio (8)**
25. Panne technique → P une autre cabine / Home Studio / revenir demain.
26. Voix fatiguée → repos (+1 tick) / forcer (−3, risque vocal) / P un coach (+500 €).
27. Les voisins se plaignent (Home Studio) → arrêter tôt (−2) / P un studio de quartier (+1 500 €) / I (10 % d'amende de 300 €).
28. L'ingénieur du son est débutant → P un mixage externe (+1 000 €) / I (−3).
29. Dépassement d'horaires → P les heures (+20 %) / bâcler (−3).
30. L'artiste a ramené toute sa bande → R / I (−2, moral +3) / en profiter (chœurs : 30 % +3, 70 % −2).
31. Session magique, il veut continuer → P la nuit (+30 %, +3, énergie −5) / stop.
32. Le mix ne plaît à personne → P un nouveau mix (+15 %) / sortir tel quel (−4) / C (studio niveau −1, +1 tick).

**Après le featuring (8)**
33. L'invité demande plus → P +20 % / refuser (50/50) / échange.
34. L'invité envoie son couplet en retard → attendre (+1 tick) / sortir sans lui (cachet rendu à 50 %) / P la priorité.
35. Son couplet est meilleur que tout le reste → garder (qualité +3, moral de l'artiste −4) / lui demander de refaire (relation −1).
36. Son couplet est raté → garder (−3) / P pour refaire (+20 %) / couper (cachet perdu).
37. Son label bloque la sortie → P les droits (+15 %) / négocier (jet sur la réputation) / retirer le featuring.
38. Les deux artistes s'embrouillent → R / médiateur (+500 €) / I (rivalité, featuring annulé).
39. L'invité veut être l'artiste principal → refuser (relation −1) / accepter (ses fans comptent à 100 %, les tiens à 50 %).
40. L'invité poste un extrait sans prévenir → en jouer (hype +4) / R (relation −1) / I.
